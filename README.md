# Spring Core IoC and DI Lab

This project demonstrates the fundamentals of **Spring Core** using XML-based configuration.

## Concepts Covered
- Inversion of Control (IoC) and Dependency Injection (DI)
- Spring Bean configuration using `beansConfig.xml`
- Constructor and setter injection
- Object and collection injection
- Singleton and prototype
- Lombok 

## Technologies
- Java 17
- Spring Context 6.2.7
- Maven
- Lombok
