# Student Management System – Spring AOP

A simple Spring Boot project demonstrating Aspect-Oriented Programming (AOP).

## Technologies
- Java 17
- Spring Boot
- Spring AOP
- Spring Data JPA
- H2 Database
- Maven

## AOP Concepts Demonstrated
- Logging
- Performance monitoring
- Exception handling
- Before, After, After Returning, After Throwing and Around advice
- Pointcuts and Join Points
- Custom annotations
- Advice ordering

## Running the Project
1. Open the project in IntelliJ IDEA.
2. Reload Maven dependencies.
3. Run `StudentAopApplication.java`.
4. Test the REST APIs using Postman.



The project uses an in-memory H2 database.
