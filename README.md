# Student Management API

A simple Spring Boot REST API for student CRUD operations using an in memory `ArrayList`.

## Technologies
- Java
- Spring Boot
- Maven

## Endpoints

| Method | Endpoint |
|---|---|
| GET | `/api/v1/students` |
| GET | `/api/v1/students/{id}` |
| POST | `/api/v1/students` |
| PUT | `/api/v1/students/{id}` |
| DELETE | `/api/v1/students/{id}` |
