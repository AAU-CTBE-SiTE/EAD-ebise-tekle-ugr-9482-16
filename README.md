# **LAB 1: JAVA MAVEN STARTER PROJECT**

## **Introduction**

A basic Java project using Maven, JDBC, and MySQL to manage student records.

## **Technologies**

* **Java** — Programming language
* **Maven** — Build and dependency management
* **JDBC** — Database connectivity
* **MySQL** — Database management
* **IntelliJ IDEA** — Development environment

## **Features**

* **Create:** Add students
* **Read:** View student records
* **Update:** Modify student ages
* **Delete:** Remove student records

## **Database Setup**

Create a MySQL database named `studentdb` with a `students` table containing `id`, `name`, and `age` columns.

## **Learning Outcomes**

Practiced Java, Maven, JDBC, MySQL CRUD operations, and Git/GitHub.
